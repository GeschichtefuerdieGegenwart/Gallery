# Erst denken, dann zeigen

Vier Kurzfilme über digitale Lernseiten für Geschichte, Gemeinschaftskunde, Psychologie und Demokratiebildung
(zusammen rund 16 Minuten, ohne Ton). Die Seite ist statisch: kein Skript, keine Cookies, keine fremden Server.

- `index.html` – die Seite (erzeugt, nicht von Hand ändern)
- `filme/` – die vier Filme als MP4 (1280 × 720)
- `bilder/` – Standbilder aus den Filmen
- `schriften/` – Fraunces und Atkinson Hyperlegible Next (SIL Open Font License)

Konzept, Didaktik, Aufgaben und Texte: Mario Walter (2026). Umgesetzt mit KI-Unterstützung (Claude);
Auswahl, Prüfung und Überarbeitung durch den Urheber.
